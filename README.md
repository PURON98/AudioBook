# 📖 AudioBook - PDF to Audio Converter

A fun and practical Python application that converts PDF documents into audio books using text-to-speech technology. Perfect for studying, multitasking, or accessibility purposes.

![Python](https://img.shields.io/badge/Python-3.x-blue)
![PyQt5](https://img.shields.io/badge/PyQt5-GUI-green)
![TTS](https://img.shields.io/badge/Text--to--Speech-Enabled-orange)

## 🎯 Overview

AudioBook is a desktop application with a beautiful GUI built using PyQt5 that allows users to listen to their PDF documents. Simply upload a PDF file, press play, and let the application read it aloud for you!

## ✨ Features

- 📁 **Easy PDF Upload** - Simple file selection interface
- 🎵 **Text-to-Speech Engine** - High-quality voice synthesis
- ▶️ **Playback Controls** - Play, pause, and control reading speed
- 🎨 **User-Friendly GUI** - Clean and intuitive PyQt5 interface
- 📚 **Study Tool** - Perfect for educational purposes
- ♿ **Accessibility** - Helps visually impaired users access PDF content

## 🛠️ Technologies Used

- **Python** - Core programming language
- **PyQt5** - GUI framework
- **pyttsx3** - Text-to-speech conversion engine
- **PyPDF2** - PDF text extraction

## 🚀 Installation

### Prerequisites
```bash
python -m pip install PyQt5 pyttsx3 PyPDF2
```

### Clone the Repository
```bash
git clone https://github.com/PURON98/AudioBook.git
cd AudioBook
```

## 💻 Usage

1. Run the application:
```bash
python main.py
```

2. Click the **Upload** button to select your PDF file
3. Press the **Play** button to start listening
4. Adjust settings as needed
